Token Radar (radar-2) — a board ranking tokens by implied value, derived at runtime from TVL, sector multiples, growth, maturity and breadth. 197 rows, deterministic, no hardcoded names. Top of the board: Steakhouse Financial.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```

Then open `dashboard/index.html` to browse the board.
